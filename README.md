# 🎵 Aura Music - Ad-Free Music Streaming App

An elegant, user-friendly music streaming application inspired by Spotify with **zero ads**, **unlimited streaming**, **high-definition 320 kbps audio**, and **real-time synced karaoke lyrics**.

---

## ✨ Features

- **🚫 100% Ad-Free**: Enjoy seamless, uninterrupted music playback forever without any commercials or interruptions.
- **🎧 High Quality Streaming**: Native 320 kbps HD audio streaming for crystal-clear sound fidelity.
- **🔍 Global Search & Discovery**: Search millions of songs, albums, and playlists from any genre (Pop, Rock, Hip-Hop, Lo-Fi, Bollywood, EDM, K-Pop, and more).
- **🎤 Synced Karaoke Lyrics**: Real-time synchronized lyrics powered by LRCLIB. Tap any lyric line to jump playback directly to that moment.
- **🎛️ 5-Band Audio Equalizer**: Real-time Web Audio API equalizer with instant presets (Bass Boost, Vocal Boost, Treble Boost, Pop, Rock, Electronic, Flat).
- **📁 Local Audio Player**: Drag & drop or browse personal MP3, WAV, FLAC, M4A, and OGG tracks from your computer to play them right alongside online tracks.
- **💾 Custom Playlists & Liked Songs**: Create and organize custom playlists and favorite your top tracks, stored safely on your computer without needing an account.
- **⚡ Offline Downloads**: One-click MP3 download button to save tracks directly to your device with clean metadata.
- **🎨 Dynamic Ambient Lighting**: Dynamic background glow that automatically extracts and reacts to the album artwork's dominant color palette.
- **⌨️ Keyboard Shortcuts & Media Keys**:
  - `Space`: Play / Pause
  - `Left / Right Arrow`: Seek backward / forward 5s
  - `Up / Down Arrow`: Adjust volume
  - `M`: Mute / Unmute
  - `L`: Toggle Lyrics
  - `Q`: Toggle Queue
  - `F`: Fullscreen Mode
  - Hardware Media Keys supported via the browser MediaSession API!

## 🚀 How to Run

### Method 1: One-Click Desktop Launcher
Simply double-click the **`Launch_Aura_Music.bat`** file in this folder. It will launch the local server and automatically open the application in your default browser.

### Method 2: Command Line
Open a terminal in this directory and run:
```bash
npm start
```
Then visit **`http://localhost:3000`** in your browser.

---

## 📱 Install as a Desktop App (PWA)
1. Open `http://localhost:3000` in Google Chrome or Microsoft Edge.
2. Click the **Install** icon in the address bar (or go to `Settings > Apps > Install Aura Music`).
3. Aura Music will now run as a native standalone desktop app with its own taskbar icon and window!
